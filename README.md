# Tag Fighter 3D

An original 3D tag-team fighting game prototype built with Godot 4.4.

## Included in prototype 0.1
- Two fighters per team with a player-side tag switch
- Punch, kick and special attack logic
- Health and power meters
- Procedurally generated placeholder fighters
- Simple 3D arena, lighting, camera and touch-oriented HUD buttons

## Current limitations
This is an early prototype, not a finished game or APK. Fighter meshes are primitive placeholders. Proper character models, animation, opponent AI, hit reactions, sound, menus, Android export configuration and real-device testing are still required.

## Open locally
Import `project.godot` in Godot 4.4+ and run the main scene.
